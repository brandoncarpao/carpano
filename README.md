# Carpaño — Catálogo de Productos

Página web oficial del catálogo de productos de **Carpaño**, joyería con distinción y estilo.

🔗 **Sitio en vivo:** [https://brandoncarpao.github.io/carpano/](https://brandoncarpao.github.io/carpano/)

---

## Vista previa

Página web profesional y elegante con:
- Diseño minimalista de fondo blanco
- Tipografías premium (*Cinzel*, *Playfair Display*, *Montserrat*)
- Animaciones suaves al hacer scroll
- Navegación fija con efecto blur
- Tarjetas de productos interactivas
- Sección de contacto con WhatsApp y correo
- Enlaces a redes sociales (Instagram, Facebook)

---

## 🛠️ Tecnologías

- HTML5
- CSS3 (variables CSS, Grid, Flexbox)
- JavaScript (Intersection Observer API)
- GitHub Pages (hosting gratuito)
